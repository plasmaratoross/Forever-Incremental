# Game Design Document

## Core Vision
Forever Incremental is designed to provide a smooth, satisfying progression loop featuring clicking mechanics, passive income generation, and prestige resets (rebirths).

## Core Loops
1. **Primary Loop**: Click to gain points -> Upgrade click power / passive generators.
2. **Prestige Loop**: Reach currency threshold -> Perform Rebirth -> Reset points for permanent multiplier and Rebirth Points.

## Target Audience
Incremental and idle game enthusiasts looking for clean UI and scalable systems.
