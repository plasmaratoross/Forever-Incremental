# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-08
### Added
- Initial project structure with ES module architecture.
- Core game engine and state manager (`state.js`, `game.js`, `constants.js`).
- Click, currency, rebirth, and progression systems.
- LocalStorage save/load system.
- Responsive HTML/CSS user interface with modern glassmorphism aesthetic.
- Project documentation files (`game-design.md`, `systems.md`, `balance.md`, `changelog.md`).
